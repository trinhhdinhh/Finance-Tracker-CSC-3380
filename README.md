## How to run the program:
# *nix-like:
- Make a python virtual environment. `python -m /path/to/venv`
- Activate the virtual environment. `. /path/to/venv/bin/activate`
- `pip install flask`
- `./run.sh`
- Navigate to https://127.0.0.1:5000
# Windows:
- see this link: https://python-web.teclado.com/section07/lectures/01_hello_world_flask/
